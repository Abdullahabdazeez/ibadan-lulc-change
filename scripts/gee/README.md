# Google Earth Engine scripts

The original single-script Earth Engine workflow that was previously stored here was removed from the public repository after the 2026 scientific reconstruction because it reproduced the superseded classification and validation framework.

The final accepted reconstruction was completed as a staged workflow combining rebuilt Landsat predictor stacks, blinded human review, leakage-free calibration, locked-holdout validation, final reclassification and Stage-10 consistency audits.

Use [`../../docs/METHODOLOGY.md`](../../docs/METHODOLOGY.md) for the authoritative final method and [`../../outputs/tables/`](../../outputs/tables/) for the frozen final statistics.
