# Analytical Tables

This directory contains the machine-readable quantitative evidence supporting the **Ibadan Land-Cover Change and Urban Expansion, 2013–2023** case study.

## Published datasets

| File | Purpose |
|---|---|
| `key_findings.csv` | Consolidated headline indicators for the study area, urban expansion and landscape change |
| `lulc_area_change_summary.csv` | Class-by-class comparison of mapped area between 2013 and 2023 |
| `transition_matrix_sqkm.csv` | Complete 4 × 4 post-classification transition matrix in square kilometres |
| `classification_accuracy.csv` | Independent classification performance metrics |

## Reading the evidence

The **area-change summary** measures how much of each land-cover class was mapped in each year. The **transition matrix** goes further by identifying what each 2013 land-cover class became by 2023. Together, these datasets show both the magnitude and composition of Ibadan's physical expansion.

The central transition is **Vegetation → Built-up**, accounting for **246.104 km²**. Built-up land increased from **99.866 km²** in 2013 to **330.177 km²** in 2023, while **91.50%** of the overall study area remained in the same mapped class.

The accuracy table reports the independent validation evidence used to evaluate the final classification. Results should be interpreted with the methodological notes in [`../../docs/METHODOLOGY.md`](../../docs/METHODOLOGY.md) and the scope guidance in [`../../docs/LIMITATIONS.md`](../../docs/LIMITATIONS.md).

## Reuse

These CSV files are provided to make the quantitative results transparent and reusable for further analysis, visualisation and planning communication. Values should be cited with reference to this repository and the project methodology.
