# Final cartographic products

The superseded pre-reconstruction PNG maps previously stored in this directory were removed after the 2026 scientific reconstruction because they encoded withdrawn classifications.

The authoritative final cartographic products were generated after the Stage 10A freeze and include:

- `Ibadan_LULC_2013_Publication_Map`
- `Ibadan_LULC_2023_Publication_Map`
- `Ibadan_LULC_2013_2023_Publication_Comparison`
- `Ibadan_Transition_Map_2013_2023`
- `Ibadan_Builtup_Expansion_Map_2013_2023`
- `Ibadan_Stable_vs_Changed_Map_2013_2023`

Those binary products are preserved in the final Stage 10G public/scientific deliverable packages. This repository intentionally does not display the withdrawn map images.

For repository-safe visual summaries of the final results, see `../charts/`.
