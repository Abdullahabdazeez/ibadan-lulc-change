# Data

This repository now exposes only data products that are consistent with the **final frozen 2013–2023 reconstruction**.

## Included

- `processed/boundary/` — the metropolitan study-area boundary files retained from the project.
- `processed/tables/` — final reconstructed area, net-change and transition tables.

## Authoritative raster products

The earlier GeoTIFFs that were previously stored under `processed/rasters/` belonged to the superseded pre-reconstruction workflow and have been removed from the public repository so they cannot be mistaken for final scientific outputs.

The authoritative final raster products were frozen in Stage 10A and archived in the project's full scientific package after Stage 10G closure. Their final common footprint contains **3,578,423 30 m pixels (3,220.581 km²)** in **EPSG:32631**.

Final headline results include:

- Built-up: **99.8658 km² (2013) → 330.1767 km² (2023)**
- Net built-up increase: **230.3109 km²**
- Vegetation → Built-up: **246.1041 km²**
- Stable landscape: **91.50%**

Raw Landsat imagery is not redistributed. See `docs/METHODOLOGY.md` for the final reconstruction and validation workflow.
