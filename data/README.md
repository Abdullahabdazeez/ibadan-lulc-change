# Data

The repository contains the final processed outputs needed to inspect and reproduce the reported statistics and figures.

- `processed/rasters/`: classified 2013 and 2023 LULC rasters, transition raster, and built-up gain raster.
- `processed/tables/`: original Google Earth Engine exports.
- `processed/boundary/`: the eleven metropolitan LGA boundaries used as the study area.

Raw Landsat and Dynamic World imagery are not redistributed. The included GEE script queries the official Earth Engine collections and reconstructs the classification workflow.
